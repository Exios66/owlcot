# Entry Image Credits

Every journal entry has two images defined in its frontmatter:

- `image` — a **remote hotlink** served from Wikimedia Commons (stable CDN URL).
- `image_local` — a **committed local copy** in this folder, used automatically
  when the network is unavailable or the remote URL goes stale
  (see `tools/pick_image.py` and `hooks/images.py`).

Most images below are **public domain or CC0** from Wikimedia Commons, so no
attribution is required; a few are CC BY / CC BY-SA, which request attribution
— the provenance for every image is listed below.

HTTP 200, and save a local copy here as `NNN-<slug>.jpg`.
